7. Lärmkarte — wann ist es laut?

Jede Zelle zeigt den energieäquivalenten Dauerschallpegel (LAeq) einer Stunde. Rot/gelb = laute Stunden, blau = ruhig. So werden wiederkehrende Muster (z.B. jeden Abend, nachts) auf einen Blick sichtbar.
